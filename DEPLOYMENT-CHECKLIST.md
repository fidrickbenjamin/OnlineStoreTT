# Deployment acceptance checklist

## Public browsing

- [ ] All seven hubs are visible where enabled, including Service Hub on the splash screen.
- [ ] Header account dropdown appears above navigation and seasonal elements.
- [ ] “Shop categories” opens category browsing; “Explore the shop” leads to products.
- [ ] Search shows a loading state before results, rather than a misleading zero count.
- [ ] Empty hubs/offers show a useful alternative.
- [ ] Every footer help link opens the correct page and contact links use the correct number/email.

## Food and stores

- [ ] Add Small and Large versions, a side and a drink. Add an extra and change quantity.
- [ ] Visit another hub, return and refresh: the same business basket remains.
- [ ] Another business has its own basket. Unavailable/removed selections are flagged.
- [ ] Sign in from the order page and return to that page with the basket retained.
- [ ] Submit one controlled order: its basket clears only after success; My activity contains the order.
- [ ] Verify received → preparing → ready → picked up → delivered in your existing operations workflow.

## Main-shop delivery

- [ ] Add an approved Wesley fee under Marketplace delivery and confirm its covered communities.
- [ ] The cart and shipping page display that option and instructions.
- [ ] An address in Wesley cannot use Roseau's fee.
- [ ] An unlisted community shows the contact/quotation path and is not offered a free delivery workaround.
- [ ] Order review and payment show the same server-confirmed delivery amount and total.
- [ ] Change a rate before a new checkout: the customer must review the changed quote.
- [ ] Existing orders keep their original delivery amount even when settings change.

## Service Hub

- [ ] Create a service business, upload a photo, add services/pricing and weekly hours; approve it.
- [ ] The name appears in quick-selection buttons and dropdown; details can be edited and archived.
- [ ] Pending, suspended, archived and paused-category listings are not publicly shown.
- [ ] Search, category/community filters and Open now work. Open now includes only businesses with configured weekly schedules.
- [ ] An owner can submit/edit their own listing but cannot edit another business. Edits return to Pending.
- [ ] Health publication is blocked until admin checks credentials/permission.
- [ ] A signed-in customer can submit a callback request once, view it and cancel an open request.
- [ ] Admin marks contacted/resolved; the customer sees the new status. A closed request cannot be reopened accidentally.
- [ ] Pausing Service Hub blocks new enquiries, while existing enquiry history is accessible.
- [ ] Catalogue, Operations and Settings staff see only permitted sections/data.

## Mobile, keyboard and real payments

- [ ] Check iPhone XR/Safari and Android Chrome, portrait/landscape and the on-screen keyboard.
- [ ] Check the menu tabs, variant tiles, floating plate, safe-area clearance, maps and dropdowns.
- [ ] Test keyboard focus, category labels, quantities and delivery selectors with a screen reader.
- [ ] Run PageSpeed/Lighthouse and record mobile/desktop results; no speed score is claimed by this update.
- [ ] Use authorised provider test arrangements for PayPal and ShopDM success, cancellation and failure.
- [ ] Check cash and Mobanking recording, order notifications, email delivery and refund/cancellation handling.
- [ ] Confirm product pack contents/weights, fees, tax applicability and policy wording against your actual business operations.
